# SOLANO

**[Baixar o Solano.exe](https://github.com/bota2202/Solano/raw/main/Solano.exe)** e abrir. Não precisa instalar.

O jogo procura atualizações sozinho ao abrir: quando sai uma versão nova, ele baixa, troca o arquivo e reabre. O save fica guardado à parte e não se perde.

## Novidades da 1.1.0

- Primeira versão com atualização automática.
- Dificuldades revistas: inimigos com 50%, 100% e 200% de vida; chefes com 90%, 115% e 200%.
- Chefes mudam com a dificuldade (Olho, Ciclope, Sentinela, Rainha e Nyxargoth). O buraco negro ficou bem mais difícil.
- Cada planeta tem um tipo de inimigo obrigatório, mostrado no mapa.
- Menos escudo e menos dinheiro; os primeiros níveis de piloto sobem mais rápido.
- Ícones novos para os poderes e tela de carregamento com a capa.
